# Phase 3, Wave 2: Modal Verbs and Entailment Logic

## Objective
Support modal verbs (must, can) and update the reasoning engine to handle modal necessity and factive entailment.

## Tasks

<task>
<read_first>
- `src/hipai/synthesis.py`
</read_first>
<action>
1. In `src/hipai/synthesis.py` (`add_belief`), update existing patterns (1, 2, 4, 5, 8) to detect modal auxiliaries:
   - "must be", "can be", "should be", "must [verb]".
   - Set the `modality` field in the resulting `Observation` or `Relation`.
</action>
<acceptance_criteria>
- "Socrates must be a man" results in an Observation with `modality="must"`.
- "Bob can see Alice" results in a Relation with `modality="can"`.
</acceptance_criteria>
</task>

<task>
<read_first>
- `src/hipai/synthesis.py`
</read_first>
<action>
1. Update `evaluate_hypothesis` in `src/hipai/synthesis.py` to account for intensional logic:
   - **Modal Necessity**: If a hypothesis $P$ is checked, and the graph contains $Must(P)$, it is Entailed.
   - **Factive Attitudes**: If $Know(X, P)$ is in the graph, $P$ is Entailed.
   - **Non-factive Attitudes**: $Believe(X, P)$ does NOT entail $P$ (it remains Undetermined unless queried specifically).
</action>
<acceptance_criteria>
- Hypothesis "Socrates is a man" returns Entailed if the graph contains "Socrates must be a man".
- Hypothesis "Humans are mortal" returns Entailed if the graph contains "Bob knows that humans are mortal".
</acceptance_criteria>
</task>
