# Integrations

## External Systems
- **FalkorDB**: Integrates via `falkordb-python`. The system expects a running FalkorDB instance (likely on `localhost:6379`).
- **MCP Clients**: Exposes a rich set of tools to MCP clients (like Claude Desktop) for interactive reasoning.

## Library Integrations
- **HuggingFace (Sentence-Transformers)**: Downloads and caches models for vector embedding generation.
- **Deductive Logic**: Montague-style semantics integrated into the Python runtime for formal expression composition.
